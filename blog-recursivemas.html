Recursive-MAS MiniCPM

Edge-Optimized Recursive Thinking with Mixed Attention Architecture

🔒 Locked — Active Development
PyTorch Transformers Grouped Query Attention Rotary Embeddings Linear Attention DCT Compression

Summary

This project implements an edge-optimized recursive-thinking multi-agent system designed to reduce inference overhead while maintaining reasoning quality. The architecture uses a custom transformer with mixed linear and full attention patterns, Grouped Query Attention for memory efficiency, and experimental weight compression techniques.

Status: Currently in active development and testing. Full technical details, implementation specifics, and performance benchmarks will be published once the research is complete and validated.

High-level approach:

  • Custom transformer implementation (no external dependencies)
  • Mixed attention pattern balancing efficiency and expressiveness
  • Memory-optimized attention mechanisms for edge deployment
  • Experimental frequency-domain weight compression

Multi-Agent Cleaning Robot

Cooperative Reinforcement Learning with Independent PPO & MAPPO

🕒 14 min read Work In Progress — No public repo yet
PyTorch Reinforcement Learning PPO MAPPO GAE Gym Environment

Overview

A cooperative multi-agent reinforcement learning system where three agents must learn to clean 24 dirt tiles on a 12×12 grid while avoiding 14 fragile obstacles — all within a 50-step time limit. The project implements both the Gym-style environment and two PPO variants (Independent PPO and Multi-Agent PPO) entirely from scratch in PyTorch.

The challenge isn't just cleaning — it's cooperative cleaning. Agents must learn to partition the grid, avoid redundant coverage, and coordinate their movements without explicit communication. The fragile obstacles add a penalty dimension: stepping on one incurs a cost, so agents must learn spatial awareness alongside cooperation.

Environment Design

Grid World

The environment is a 12×12 grid with:

  • 3 agents — Each with position, orientation, and a 5-channel observation
  • 24 dirt tiles — Randomly placed; includes normal dirt (+2 reward) and heavy dirt (+4 reward). Cleaned when an agent moves onto them.
  • 14 fragile obstacles — Stepping on one incurs a -20 penalty. Agents must learn spatial awareness alongside cooperation.
  • 50-step episode limit — Forces efficient exploration. Early termination on full cleanup.

Observation Space

Each agent receives a 5-channel 12×12 observation tensor:

  1. Fragile object locations
  2. Self-position (one-hot)
  3. Other agents' positions
  4. Explored history (visited tiles)
  5. Docking position marker

The state tensor is formatted as [batch, H, W, C] and permuted to [C, H, W] for PyTorch Conv2d compatibility.

Action Space

5 discrete actions per agent: idle, up, down, left, right. Agents cannot move through obstacles or other agents. Boundary violations incur a -20 penalty.

Reward Structure

The reward function is carefully shaped to encourage efficient cooperative cleaning:

  • +2 for cleaning a new tile (normal dirt)
  • +4 for cleaning heavy dirt
  • -1 for revisiting an already-cleaned tile
  • -0.1 per timestep (time penalty)
  • -0.1 for idle action (encourages movement)
  • -20 for boundary/fragile object/inter-agent collision violation
  • +20 completion bonus for cleaning all tiles

Safety Layer

A configurable safety enforcement layer (use_safety=True/False) detects boundary violations, fragile object collisions, and inter-agent collisions. When enabled, violations are blocked; when disabled, agents learn to avoid them through negative rewards.

Visualization

Matplotlib-based interactive renderer with colored zones, agent trails, per-agent exploration overlays, and dock markers. Useful for debugging learned policies and understanding agent coordination patterns.

Algorithm Implementations

Independent PPO (I-PPO)

Each agent maintains its own policy network, value function, and trajectory buffer. Agents learn independently — there's no shared information during training. This is the simplest multi-agent RL approach and serves as a baseline.

Key details:

  • Per-agent trajectory buffers (no mixing)
  • Independent advantage estimation via GAE
  • Separate policy gradient updates per agent
  • No communication between agents during training or inference
  • Rollout buffer of 400 timesteps, 32 epochs over collected rollout, batch size 100
  • Hyperparameters: GAMMA=0.98, LAMBDA=0.97, ACTOR_LR=6e-4, CRITIC_LR=7e-4

Multi-Agent PPO (MAPPO)

MAPPO introduces a shared global critic while maintaining independent actor policies. The critic has access to the concatenated aggregated state space (all agents' observations), enabling it to learn a centralized value function that accounts for the joint state.

Key details:

  • Independent actors (one policy per agent)
  • Shared global critic (centralized value function)
  • Critic input: concatenated observations from all agents (fragile_map + self+other overlap + combined exploration + docking)
  • Global critic provides shared value estimate used for GAE computation across all agents
  • Shared critic updates from combined batch of all three agents' transitions
  • Hyperparameters: GAMMA=0.98, LAMBDA=0.97, EPSILON=0.15, ACTOR_LR=5e-4, CRITIC_LR=6e-4

The hypothesis is that MAPPO should outperform I-PPO because the centralized critic can learn the cooperative structure of the task — understanding that agents cleaning different regions is better than redundant coverage.

Continuous Episode Variant

A third variant that runs until the episode naturally terminates (all dirt cleaned) instead of using a fixed 400-step rollout buffer. This demonstrates the trade-off between fixed-horizon and natural-termination collection strategies.

Key differences:

  • Includes GAE normalization step (zero-mean, unit-variance per mini-batch) before PPO update
  • Uses torch.nn.functional for MSE loss and categorical distributions directly instead of manual log-ratio computation
  • Better suited for environments with variable episode lengths
PPO Core (Shared Across All Variants)
  • Clipped surrogate objective with ε = 0.15
  • Value loss coefficient c₁ = 0.5
  • Entropy bonus coefficient c₂ = 0.03 (encourages exploration)
  • Generalized Advantage Estimation (GAE) with γ = 0.98, λ = 0.97
  • Rollout buffer collection with fixed-horizon or continuous episode natural termination

Network Architecture

CNN Policy Networks

The primary architecture uses convolutional layers to process the spatial grid observation:

  • Actor: Conv2d(5 → 6, kernel=3, dilation=2) → Conv2d(6 → 8, kernel=5) → Flatten → Linear(128 → 64 → 64 → 5) with GELU activations → Softmax over 5 actions
  • Per-Agent Critic (I-PPO): Same CNN backbone as actor, Linear(128 → 64 → 64 → 64 → 1) outputting scalar state-value
  • Global Critic (MAPPO): Conv2d(4 → 6, dilation=2) + Conv2d(6 → 8, 5) → Flatten → Linear(128 → 64 → 1); takes concatenated global state (fragile + overlap of self+others + combined explore mask + docking)

The dilated convolution (dilation=2) is critical — it allows the network to "see" a larger receptive field without increasing parameters, important for a 12×12 grid where agents need global awareness.

Fully-Connected Ablation Models

As a baseline comparison, fully-connected networks (ActorRec / CriticRec) were also implemented: raw flatten(12×12×5=720) → Linear(720 → 128 → 64 → 64 → 5/1). This measures the value of spatial inductive bias in this task.

Training Infrastructure

  • Batch shuffling: Custom shuffled_batch_generator produces shuffled mini-batches for stochastic gradient updates
  • GPU-accelerated training: CUDA device placement with torch.permute for channel-first convention
  • Checkpoint save/load: Automatic with torch.save() / torch.load(weights_only=True) for safe weight restoration
  • Metric logging: Reward curves, entropy, clip loss, value loss — exported as NumPy arrays and plotted via matplotlib with tab10 colormap
  • Per-agent checkpoints: Saved as ippo_actor_random_{id}.pt, ippo_critic_random_{id}.pt

Lessons Learned

  • GAE normalization matters. Without zero-mean/unit-variance normalization of advantages, training is unstable and diverges quickly. This is especially true in multi-agent settings where reward scales can vary dramatically between agents.
  • Entropy scheduling is non-trivial. Too much entropy → agents wander randomly. Too little → agents converge to "stay still" (safe but useless). A decay schedule works better than a fixed coefficient.
  • Centralized critics aren't magic. MAPPO's shared critic requires careful architecture — if the concatenated state space is too large, the critic overfits. Dimensionality reduction or attention mechanisms might help.
  • Environment design is 80% of the work. Getting the reward function right (balancing cleaning reward vs. obstacle penalty vs. time penalty) took more iteration than the RL algorithms themselves.
  • CNNs beat MLPs for spatial tasks. The dilated convolution architecture significantly outperforms the fully-connected baseline, confirming that spatial inductive bias matters even in small grid worlds.
